# personal_throne

《王座与黄金》（Throne & Gold）——单机奇幻角色扮演 / 经营策略 / 动态世界模拟。

- 玩法与世界观：[design.md](design.md)
- 工程计划与排期：[development-plan.md](development-plan.md)

## 开发

```bash
pnpm install
pnpm dev      # 本地开发
pnpm build    # 产出单文件 dist/index.html
pnpm test     # 单元与确定性回归
```

> 当前仓库处于 M0 之前的规划阶段，构建配置尚未创建。
