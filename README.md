**M7 阶段 1 可玩性抢救：完成。** 新开局默认进入真抉择（此前全部被自动代选）；事件弹窗按「自己 → 家族 → 组织 → 地区 → 国家」分级，

玩家死亡会弹出讣告与继承人选择（配偶 → 子女 → 兄弟姐妹 → 同家族），也可以选择就此落幕；自动存档改为每 30 天真正写入。
新增 3 条带抉择的人物事件与 6 个信号分级用例。seed `stage1-check` 25 年实测：玩家抉择 12 次、弹窗主体命中 100%、相关事件占比 7.9%。

**M7 阶段 2 经济闭合：完成。** 贸易按「采购 + 运费在发船时入账、到港补关税」单一口径记 COGS（此前利润虚高约 5 倍）；
盈利组织按当月净利 30% 给股东分红（新增 `dividendsPaid` 统计）；公职俸禄按月从国库发到在任者手里；
人头税基数提高、国库储备从 6 个月放宽到 30 个月刚性开支，国库与组织现金回到同一量级（5 年 0.153、20 年 0.055）；
新增 `train` 命令与玩家卡训练入口。十年「Δ权益 + 分红 / 税后净利」= 0.996。

**M7 阶段 3 个人动词与行动力：完成。** 每月 3 点行动力（上限 6）、健康 0–100；新增 `move`（沿商路移动，按在途天数推进时钟）、
`trade_goods`（买卖价差 + 运费，亏本拒绝）、`seek_audience/gift/gossip`（关系、洞察）、`rest`、`deposit/withdraw`（本地银行），
`train` 也消耗行动力；开局行市按地形给出 ±10% 差异，第一天就有可贩运价差。seed `active-idle` 实测：首年可用动词 8 个，
40 年主动经营净财富 **136,924** vs 完全躺平 **59,537**（**2.30×**，验收 ≥2×）。

**M7 阶段 4 叙事系统：完成。** 历史记录写入时把裸 id 换成专名（人物/组织/国家/地区）并附主体与地点；事件新增 `when` 世界门控
（「石渡关雪崩」只发生在高谷），标题与正文支持 `{country}/{place}/{subject}` 占位符；新增 42 条本地事件（7 国 × 6 条）；
编年史面板按「年-月」分组、日期只显示一次、带地点签与「你」标记。20 年 12,617 条记录实测：含专名 **100%**、裸 id **0 条**。

**M7 阶段 5 目标与新手：完成。** 左下角常驻「建议事项」三条：休息 / 贩货 / 买股 / 谋公职 / 晋升 / 训练，
每条都带真实数字（差价净利、股份价格、公职评分、训练花费），点「去做」直接执行。

**M7 阶段 6 模拟深化：完成。** 战争经济（交战国的市场需求 ×1.12、商路运力 ×0.55）；继承政治（统治者死亡必触发继承危机、
未成年统治者自动由成年摄政代政）；种族寿命差异化（精灵约为人类三倍）；家族声望随成员公职累积；NPC 之间每年自行结盟或结怨。
三 seed 100 年：破产率 20.8–28.0%、分裂率 8.3–12.0%、继承危机 45–49 次。

**M7 阶段 7 打磨与发布：完成（v2.0.0）。** 创建人物的职业/地区/技能与组织类型全部中文化，抉择弹窗正文对比度提高；
性能复测 100 年 3.26–3.33 s（D7 预算 14 区 < 4.0 s）；版本号 2.0.0；36 个测试文件 / 221 个用例全绿，
`release/index.html` 387,000 字节（体积预算 24.6%）。
玩家卡新增「野心」行（富甲一方 / 权倾朝野 / 名动四方，按职业推导）与「第 N 章」标题；玩满 30 天弹一次「第一份财报」（现金、行动力、健康与野心进度）。

**阶段 1「让做事成为最优解」：完成。** 月俸只在玩家 60 天内亲自出手时发放（NPC 不受影响），180 天不出手不再晋升；
每月扣身家 0.4% 的生活开销（最低 10 铜，玩家卡显示「每月开销」）；贩货商路从「相邻」扩到「两跳以内」，载货量随贸易与生涯等级增长
（5 + 贸易 + 生涯×2），采购/出售基准改为 1.02/0.98。实测同一世界 20 年：躺平 1,500→3,222，主动 1,500→6,681（**2.07×**）。
三 seed 100 年：破产率 41.7–45.8%、分裂率 8.7–16.7%、均价偏离 11.2–13.3%（破产率高于目标，留给阶段 2/4）。

**阶段 2「账本闭合」：完成。** 工资按组织手头现金**按比例**发给在岗成员（此前现金不够就一个人都不发），欠下的工资补发时真的打进成员钱袋（此前只减账面、钱凭空消失）；国家俸禄不再被扣两次；国债有了债权人——赤字向本国银行/富商借，还本与利息都流回组织，10 年存量国债 98% 记在组织名下。实测生涯月俸 **100%** 到人（验收 ≥90%）。遗留：货币总量 10 年仍 +133.7%，家庭钱袋与物价响应还没做。

**阶段 3「失败与边界」：完成。** 死亡后所有命令都被拒绝；NaN、原型链名字、缺失字段在命令入口就被挡下（此前一条 `units: NaN` 的贩货能把玩家财富写成 NaN 并存进档案）；同版本存档缺哈希不再免检；数组形态的老契约会先归一化成对象再补字段。
**玩家人物卡：完成。** 左栏玩家卡底部直接展开一张「我的人物卡」（档案、阵营九宫格、六维），不用切到人物面板；技能与性格全部用中文名，弹窗里不再出现 `{country}` 之类的裸占位符，进入游戏默认 1× 推进。

**阶段 6「界面与性能」：完成。** 辅助文字对比度从 3.14:1 提到 4.5:1 以上（四种底色逐一验证），小于 12px 的字号全部抬到 0.75rem；标签页补上 role 与 tabindex、支持方向键切换，四个弹窗都装了焦点陷阱，开局选择期间时间停住；引导第二步改成「行动力花在哪」。性能上，月度工资结算由逐组织全表扫描改为一次索引，编年史折叠只扫数组尾部窗口——100 年模拟 3.4 s，测试门禁从 8 s 收紧到 4 s。

**阶段 5「叙事」：完成。** 编年史不再是一天几十条的账本流水：贸易与收支按月折叠成一条「本月账本」，事件带上正文与结算明细，死亡写出谁、在哪、享年与遗产，继位写出谁接了谁与继承依据，战争战报带地点与折损。玩家自己的训练、休息、打听行市、贩运与借贷都会记在你的名下，账本折叠时也保留归属。编年史默认「只看大事」。40 年实测：大事占 72.2%，最高同款模版 14.0%，玩家相关 15.3%（验收线 25% / 40% / 5%）。

**阶段 4「继承法与僵尸国」：完成。** 开局给每位在位者补上配偶与两个孩子，君主制按血亲顺序继承（子女→兄弟姐妹→侄甥→配偶），选举制里的「政治世家」也更容易把位子传给自家人；摄政限定 25–70 岁。失去全部领土的国家挂账 48 个月后灭亡并退出一切战争与外交，不能复活；已解散的组织不再被旧领袖的死亡拉回危机，遗产与退休股权统一兜住 100% 上限。实测 100 年子女继位率 48.4% / 66.7% / 46.2%（三 seed），0 地区国最长存活 32–48 个月。

**d20 检定与弹窗暂停：完成。** 抉择按钮会写明「力量检定 d20+2 ≥ 12」，成功与失败走不同后果；抉择一旦出现就不会被系统代选，世界继续走，你想好再点；**打开弹窗时时间自动暂停，关闭或做完决定后回到原来的速度**（手动暂停优先），顶栏「待决抉择 N」可以随时把没处理的抉择重新打开。

**成长与旅行（P1–P3）：完成。** 技能每级都折成数字（贸易 −1% 买价 / +1% 卖价、单次贩货 5+等级；谈判 −2% 利率；说服 +0.01 游说；洞察 +8% 打听），生涯四阶月俸 0/40/120/300 真的到账；地区页「此地的机会」列出贩货净利、可谋公职评分、可签约总部与钱庄，并显示「前往」的天数与路费；谋职/游说须在首都、签约须在总部、赴宴与考察成为新的到场理由。见 [docs/growth-travel-design.md](docs/growth-travel-design.md)。

**界面调整：行动分组与城市前往。** 左侧个人行动按修养/生计/钱庄分组，移动入口从左侧移除；右侧点城市会显示「路程 N 天 · 路费 M 铜」与「前往」按钮，点击后自动推进在途天数。

## 环境要求

- Node.js ≥ 22
- pnpm 11（`packageManager: pnpm@11.28.5`；`corepack enable pnpm` 或 `npm i -g pnpm`）

## 命令

```bash
pnpm install        # 安装依赖
pnpm dev            # 本地开发（Vite HMR）
pnpm build          # 类型检查 + 产出单文件 dist/index.html
pnpm release        # build + 校验（无外链 / ≤ 1,572,864 字节）+ 复制到 release/index.html
pnpm preview        # 预览构建产物
pnpm typecheck      # 仅类型检查
pnpm lint           # ESLint（架构依赖方向、Math.random 与 new Date 禁令）
pnpm test           # vitest run：33 个文件 / 207 个用例
pnpm test:watch     # 监听模式
pnpm format         # Prettier
pnpm sim --years 100 --seed demo-seed            # 无界面快进，打印哈希 / 耗时 / 破产率 / 分裂率 / 价格偏离 / 关税
pnpm sim --years 100 --seed demo-seed --check    # 复跑并比对状态哈希，不一致则退出码 1
```

`pnpm sim` 由 `tsx` 直接执行 `scripts/sim.ts`（开发期依赖，不进产物；`scripts/` 不在 `tsconfig.json` 的类型检查范围内，仅在 `pnpm build` 之外单独运行）；默认 `--years 100 --seed demo-seed`。

## 发布

`pnpm release` = `pnpm build` + `node scripts/release.mjs`。脚本逐项校验：文件存在且非空、
无 `<script src>` / 外部 `<link href>` / `@import url(http…)` / `url(http…)`、≤ **1,572,864 字节**，
通过后才复制为 `release/index.html`；任何一项失败都不会产生半成品。

- `release/index.html` 是**仓库内可下载的成品**，每个阶段完成、验证通过后更新并提交；CI 用
  `git diff --exit-code -- release/index.html` 校验「提交的产物 == 当前源码构建结果」；
- `dist/` 只是构建缓存，不进仓库；
- 版本对齐 `package.json` 的 `version`，HTML 里写入 `<title>` 与页脚版本号。

## 架构速览

```text
src/core/        状态内核 + 编排层（顶层 9 个模块：GameEngine / WorldState / GameClock / CommandBus /
                 EventEngine / Random / History / SimulationTier / Chronicler；子目录 schema/ 类型、
                 commands/ 按域命令、event/ 事件管线均 ≤ 600 行）
src/systems/     8 个业务域、34 个结算文件：
                 character/(15) organization/(7) country/(4) economy/(3) goals/(2) military/(1) npc/(1) region/(1)
src/content/     静态内容与数值配置（14 个 JSON 由 index.ts 装配：goods/organizations/countries/world/
                 balance/faiths/backgrounds/names + events/6 个）
src/storage/     存档信封、迁移（v1→v9）、IndexedDB 槽位、导入导出
src/ui/          原生 DOM 组件 + SVG 地图（29 个 .ts + styles/base.css；app/ 与 map/ 子目录）
                 全部源文件 ≤ 602 行（最大为 core/GameEngine.ts）
scripts/         sim.ts（快进 CLI）、release.mjs（发布校验）
tests/           33 个回归用例文件 + helpers
release/         仓库内发布的成品单文件
```
