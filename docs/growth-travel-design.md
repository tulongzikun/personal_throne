# 成长与旅行：让「点数」有用、让「出门」有理由

> 2026-11-20 · 针对玩家反馈的两条问题给出方案
>
> 1. 成长有点数，但看不出点数的用处；
> 2. 前往其他地方要花成本，但为什么要去？

现状核查（代码事实）：

- 技能只影响三处：生涯晋升的 `minSkill`、公职评分（权重 0.55）、少量事件条件。界面上只显示「贸易 6」，没有任何「6 能做什么」。
- 六维属性只影响技能上限（`skillCap = 3 + floor(attr / 3)`）和健康/死亡率，训练到上限时只给一句「已到上限」，没告诉玩家上限从哪来。
- 生涯等级 `careerRank` 只写进称号、声望与野心进度，**没有任何玩法收益**。
- 移动成本 = `天数 × 2` 铜 + 1 行动力 + 2 健康；但地区页只写价格表，不写「这里能办什么」，玩家没有去的理由。
- 公职、游说、契约都可以远程办：`applyForOffice` 只要求「在本国居住」，`lobby` 在你不在场时也能花组织的钱改政策。

---

## 一、成长：三条腿，每条都看得见

### 1. 技能：每级都有具体效果（写进 tooltip 与事件文案）

| 技能 | 每级效果 | 谁在用 |
|---|---|---|
| 贸易 trade | 采购价 −1%/级、出售价 +1%/级；单次贩货上限 +1 单位/级 | 贩货、契约定价、财务大臣 |
| 谈判 negotiation | 契约利率 −2%/级（最低 1%/月）；违约金 −5%/级 | 借贷、供货契约 |
| 说服 persuasion | 游说单次幅度 +0.01/级（上限仍 0.2）；公职评分 | 游说、首相/议长 |
| 洞察 insight | 打听成功率 +8%/级；事件预兆多 1 条/3 级 | 打听、抉择提示 |
| 律法 law | 公职评分；政体变更时保住职位 | 公职、继承危机 |
| 格斗 melee / 战术 tactics | 遇袭存活、军团战力（已有） | 冒险、战争 |
| 威吓 intimidation / 潜行 stealth / 估值 appraisal / 工艺 craft | 事件选项条件、走私/估价/制造 | 事件、黑市 |

界面：技能行悬停显示「贸易 6：采购 −6%、出售 +6%、单次可贩 11 单位」。

### 2. 属性：六维决定「能练到多高」

- 上限公式不变：`技能上限 = 3 + floor(属性 / 3)`（属性 10 → 6，属性 16 → 8）。
- 属性来源写清楚：
  - 开局天赋 3 个标签，各 +2（单维 ≤16）；
  - 每 10 年一次「阅历」：已用主属性 +1（上限 20）；
  - 事件奖励（导师、奇遇）；
  - 后期装备/头衔（M8 再做）。
- 训练到上限时，按钮文案改成「已达上限 8：需要 体质/智识 ≥ 16」而不是简单置灰。

### 3. 生涯：四阶各有被动收益与权限

| 阶 | 称号 | 月俸/抽成 | 解锁 |
|---|---|---|---|
| 0 | 学徒 / 新兵 / 书吏 | 0 | 基础动作 |
| 1 | 伙计 / 老兵 / 议员 | 40 铜/月 | 可签 1 份供货契约 |
| 2 | 行商 / 队长 / 大臣 | 120 铜/月 | 可开商路；贩货上限 +5 |
| 3 | 商会主 / 佣兵团长 / 执政 | 300 铜/月 | 可任免本组织掌柜；公职评分 +0.1 |

界面：玩家卡「生涯」行改成进度条：`行商（2/3）· 下一阶 商会主：4,000 铜 ✓ / 贸易 9（当前 6）`。这就是可见的成长路线。

### 4. 公职：七席是「成长的天花板」，也要写清门槛

- 每席显示：所需技能、当前评分、门槛 45、月俸、影响力。
- 公职收益：月俸（已有）+ 影响力（政策支持度）+ 特权：
  - 财务大臣：可见全国税率与国库，每月一次「提请减税」；
  - 元帅：军团维护费 −10%；
  - 首相/议长：可发起一次政体改革（高门槛）。

## 二、旅行：把「必须到场」的机会放到地图上

### 1. 地区页新增「此地的机会」（核心改动）

每条机会都带**预估收益**与**此行成本**，玩家一眼能算账：

```
铁峰堡 · 此地的机会
· 铁价 18（银月 31）：贩 5 单位净赚约 60，扣路费 8 → 净 52
· 铁峰矿社总部：可谈供货契约（谈判 4，利率约 1.4%/月）
· 自由之刃兵营：可雇佣护卫（1 行动力，30 天）
· 王庭不在此地
```

```
银月城 · 此地的机会
· 王庭：谋求财务大臣（评分 48 / 门槛 45，月俸 110）
· 王庭：游说关税 −0.05（需 1 行动力，组织出 250 铜）
· 织锦行会总部：可买入 5% 股份
```

没有机会的地区显示「此地暂无你的机会」，地图节点置灰，避免白跑。

### 2. 在场规则：三件事必须本人到

| 动作 | 现在 | 改为 |
|---|---|---|
| 谋求公职 | 在本国居住即可 | **必须在该国首都**（王庭/议会所在地区） |
| 游说政策 | 任意地点花组织钱 | **必须在首都**，或本人持有该国公职（可远程） |
| 签契约 | 任意地点 | **必须在该组织总部所在地区** |

### 3. 新增两个「值得跑一趟」的动作

- `attend_court`（赴宴）：首都限定，1 行动力 + 50 铜，关系 +8，可能触发宫廷事件（封赏/被卷入派系）。
- `inspect_market`（考察市场）：异地限定，1 行动力，30 天内该地价格在 UI 可见（否则只有模糊区间），让「跑一趟再回来贩货」成立。

### 4. 成本透明

「前往」按钮旁固定显示：

```
前往：4 天 · 8 铜 · 1 行动力 · 2 健康
此行可办：谋求财务大臣、游说关税
```

行动力不足时提示「本月还剩 0 点：下个月初恢复 3 点」。

## 三、数值校准（让期望收益 ≥ 3 倍成本）

| 行为 | 成本 | 期望收益 |
|---|---|---|
| 邻区贩货 5 单位 | 8 铜 + 1 行动力 + 4 天 | 毛利 40–80 铜 |
| 赴首都谋公职 | 8–16 铜 + 1 行动力 + 4–8 天 | 月俸 110–140 铜，持续任职 |
| 赴首都游说关税 | 250 铜（组织出）+ 1 行动力 | 关税 ±0.05，影响全国贸易数百铜/月 |
| 考察市场 | 1 行动力 + 路费 | 后续 30 天贩货多赚 20–40/趟 |

原则：**一次出行 ≤ 4 天**（月内可往返），否则玩家会因为「这个月什么都干不了」而放弃。

## 四、实施顺序（每阶段可独立上线）

### P1 透明化（不改规则，半天）

1. 技能 tooltip 与「用途」表；
2. 生涯进度条（下一阶差多少铜/技能）；
3. 地区页「此地的机会」列表（先只读展示：价格差、总部、王庭、银行）；
4. 前往按钮补全成本行与「此行可办」。

### P2 在场规则（1–2 天）

1. `applyForOffice` 增加首都校验；`lobby` 增加「在首都或持公职」校验；`sign_contract` 增加总部校验；
2. 新增 `attend_court`、`inspect_market`；
3. 建议事项同步：当玩家不在首都且有公职机会时，建议「前往 X 谋职」。

### P3 成长收益（1 天）

1. 技能等级接入贸易折扣、贩货上限、契约利率；
2. 生涯月俸与权限（供货契约数、开商路、贩货上限）；
3. 公职特权（财务大臣可见税率、元帅维护费 −10%）。

### 验收

- 首次游戏 60 秒内能说出「我的下一步是去首都谋财务大臣」；
- 任意一次出行，玩家能在界面上看到成本与「此行可办」；
- 每个技能等级至少对应一个可见数字变化；
- 40 年主动玩法净资产 ≥ 躺平 2.5×（当前 2.30×）；
- 测试：`tests/growth-visibility.test.ts`、`tests/travel-purpose.test.ts`。
