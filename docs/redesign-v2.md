# 《王座与黄金》v2 重构设计

日期：2026-11-20 · 基线 `2cd83c2`（v1.0.0） · 依据：[四维试玩报告](./playtest-2026-11-20.md)
原则：**开发量不设上限**；先设计到位，再按阶段实施；每个阶段必须可独立交付、可回滚、可验收。

---

## 0. 设计目标与北极星指标

### 0.1 一句话目标

把"一台会自己转的世界模拟器"变成"**一个人在四十年里，从字号少东家爬到王座或坟茔**"的游戏——玩家的每个决定都要落在账本、关系、名声或版图上，并且四十年后能讲出一个只属于他的故事。

### 0.2 四条体验支柱

| 支柱 | 玩家感受 | 反面（当前版本） |
| --- | --- | --- |
| **能动** | 我每个月都有 2–3 件只有我能决定的事，且代价可预判 | 25 年 4 次抉择，全部自动代选 |
| **积累** | 我的技能、股份、官位、人脉会复利，且看得见 | 40 年净资产 74% 是别人死了送的 |
| **牵动** | 世界的事件会找上我，我能看出"关我什么事" | 每秒 4.8 个弹窗，0.6% 与我有关 |
| **收束** | 我死的时候有一份讣告和一份成绩单，继承人接着玩 | 死后 `playerId` 指向尸体，世界继续跑 |

### 0.3 北极星指标（可自动测量）

| 指标 | 定义 | 现状 | v2 目标 |
| --- | --- | --- | --- |
| 决策密度 | 玩家可见抉择 / 年 | 0.16 | **≥ 12** |
| 相关度 | 玩家相关信号 / 全部信号 | 1.7% | **≥ 35%**，且相关信号 100% 命中 refs |
| 主动性收益 | 主动玩法 40 年净资产 / 躺平 | 1.21× | **≥ 3.0×** |
| 经济闭合 | 年度 Δ权益 / 年度净利润 | 0.021 | **0.85–1.05** |
| 叙事密度 | 含专名的历史记录占比 | 12.8% | **≥ 80%** |
| 财政合理 | 7 国国库合计 / 21 组织现金合计 | 0.003 | **0.05–0.20** |
| 死亡收束 | 玩家死亡后 30 天内进入继承/结算 | 永不 | **100%** |
| 性能 | 100 年模拟耗时（14 区） | 3.1 s | **≤ 3.5 s**（不因新系统退化） |

### 0.4 非目标

- 不做多人、不做实时联网、不做 3D。
- 不引入剧本引擎（事件仍由数据驱动，抉择是 `EventDef.choices` 的扩展）。
- 不重写已稳定的模拟核心（`Random`/`GameClock`/`EventEngine` 的确定性契约保持）。
- 单文件 `release/index.html`、零外链、`file://` 可运行，仍是硬约束。

## 1. 体验设计：四层循环与动词表

### 1.1 四层循环

```
日/月循环（30 秒 – 2 分钟）
  看"本月见闻" → 处理 1–2 件与我有关的事 → 做一个决定（花行动力/钱）→ 推进

季循环（5–10 分钟）
  季度结算：字号财报、政策风向、家族/关系变化 → 调整策略 → 开一条商路/换一个策略

年循环（20–30 分钟）
  年度：分红、俸禄、技能成长、生老病死、继承 → 设定明年的一个目标

生涯循环（2–4 小时）
  少年得志 / 中年扩张 / 晚年布局 → 死亡 → 讣告与成绩单 → 继承人继续（或落幕）
```

**现状 27 个命令中，玩家个人能用的只有 6 个。v2 扩到 22 个个人动词 + 10 个组织/国家动词。**

#### B. 组织行动（现有 + 扩展）

`invest`（改为"注资"，明确从组织现金出）、`deposit`/`withdraw`（玩家 ↔ 组织）、`recruit`、`open_route`、`sign_contract`、`break_contract`、`restructure`、`sell_asset`、`buy_asset`、`set_strategy`、`buy_shares`（加溢价与拒卖）、`sell_shares`、`claim_leadership`、`take_loan`、`repay_debt`、`lobby`、`pay_dividend`（主动分红，提升股价与忠诚）。

#### C. 国家行动（统治者/公职）

`seek_office`、`propose_policy`、`levy_army`、`march_army`、`declare_war`、`offer_peace`、`appoint_office`（任命他人，换取支持）、`grant_charter`（给组织特许，换税收/忠诚）、`issue_bond`（发债）、`set_tax`（在政策框架内微调）。

### 1.3 行动力与时间

- 每月 3 点行动力，月初重置；`advanceDays` 时不消耗，只有"命令"消耗。
- 跨月行动（修习 30 天、游学 90 天、迁居路途）登记为 `Activity`，在 WrapUp 结算，期间玩家不能重复同类行动。
- 目的：让"时间"成为真正的资源——加速不再是免费跳过，而是"我选择把时间花在哪"。

### 1.4 开局五种出身

| 出身 | 首小时可做的独特事 | 初始资源 |
| --- | --- | --- |
| 少东家（默认） | 买股夺权、开商路、账簿博弈 | 1,500 铜、22% 股份 |
| 行脚商人 | 贩货、跑商路、结识各地商人 | 800 铜、一车货 |
| 落魄贵族 | 联姻、求见、借债维持体面 | 头衔、负债 2,000 |
| 退伍军官 | 受雇、练兵、平叛 | 300 铜、战术 8、旧部 |
| 书吏 | 谋公职、起草政策、依附权贵 | 200 铜、律法 7、一位靠山 |

同一世界、同一规则，五种开局前 5 年的动词表不同——这是"重开一次"的理由。

### 1.5 目标系统（三层）

1. **本局野心（Ambition）**：开局从 3 选 1，例：「让金穗行的旗帜插进三国的粮市」「坐上财务大臣的位置」「建立自己的家族」。
2. **阶段目标（Chapter）**：每 5 年自动生成 1 个，如「10 年内持股 ≥ 51%」「资助一次公共工程」「让一位盟友进入内阁」。
3. **建议事项（Suggestion）**：实时派生 3 条，回答"现在能做什么"（详见 §5.2）。

完成判定一律用**派生条件**（读状态），不靠玩家手动勾选；完成时写一条 `kind:'milestone'` 的编年史，并给一次"称号/声望"奖励。

## 2. 经济重构

### 2.1 三层账本与守恒式

```
个人：现金 wealth + 个人资产 + 股份估值 + 债权 − 债务
组织：现金 + 存货 + 固定资产 − 负债 = 股东权益
国家：国库 + 应收税 − 债务 = 国家净资产
```

每月结算后必须满足（写成测试）：

- `Δ权益 = 净利润 − 分红 ± 增资/回购`
- `Δ个人财富 = 俸禄 + 分红 + 私产收益 + 交易盈亏 − 支出`
- `Δ国库 = 税收 + 关税 + 国企分成 + 发债 − 行政 − 军费 − 俸禄 − 工程 − 利息`
- 全系统现金守恒：`Σ现金(个人+组织+国库) + 在途资金 = 常量 ± 货币投放`（货币投放只允许来自"铸币/新矿"事件）

### 2.2 贸易损益修正（P0-4）

- 新增 `org.lastMonthTradePurchase`：`TradeSystem` 采购时登记，不再直接扣现金；结算时统一：
  `COGS = 采购成本 + 运费 + 关税 + 损耗`，`tradeGross = tradeRevenue − COGS`。
- `grossProfit = revenue − materialCost − payroll − admin − interest + tradeGross`。
- 现金行：`cash += revenue − materialCost − payroll − admin − interest − tax + tradeGross`。
- 验收：连续 12 个月 `ΣnetProfit` 与 `Δequity` 误差 ≤ 2%；组织页"上月利润"与权益变化一致。

### 2.3 分红与股价

- 每年末（第 360 天）：`payout = max(0, 年度净利润) × 35%`，按股比发现金；现金不足时 `payout = max(0, cash − 1.5×payroll)`，差额记"应付股利"（负债）。
- 分红后 `conflict −0.02`、股东忠诚 +，股价 = `equity × (1 + 0.15×利润率) × 行业乘数`。
- 玩家可在组织页看到"本月/本年预计股息"。

### 2.4 国家财政

- 税基：`taxBase = 人口 × 人均产出系数 + 区域内组织营收 × 0.6`，`headTax = taxBase × taxRate × collectionEfficiency`（效率随 `regulation`/腐败变化）。
- 初始 `HEAD_TAX_PER_CAPITA` 系数 0.02 → **0.06**，并修正 `countries.json` 的 `monthlyRevenue` 为模型计算值。
- 支出：行政（营收 8%）、军费（`militaryShare`）、公职俸禄（三席月薪 140/130/110）、债务利息、公共工程（可选）。
- 赤字 → 发债（`debt += deficit`，利率随债务率上升）→ 债务率过高触发政策压力/信用降级。
- 目标：7 国国库合计 / 21 组织现金合计 ∈ [0.05, 0.20]。

### 2.5 个人资金出口

- `deposit`/`withdraw`：玩家现金 ↔ 组织现金（存款记债权，年息 3%）。
- `buy_land`：个人地产，年租金 = 地价 × 8%。
- `invest_self`/`hire_guard`/`patronize`：现金换名声/安全/影响力。
- 目标：40 年终局玩家现金不再"无处可花"，至少 3 个有意义出口。

### 2.6 薪水与技能

- 公职月薪发放（140/130/110），记入 `Character.wealth` 与编年史（按季度汇总，避免刷屏）。
- `train`：30 天 + 100 铜，主技能进度 +1；`study`：90 天 + 300 铜，副技能 +1；技能上限 12。
- `officeScore` 财富项 `/20` → `/12`；商会主 `minSkill` 9 → 8；转行门槛与等级解耦（`switchCareer` 保留等级，不重置为 0）。

## 3. 叙事系统

### 3.1 `HistoryRecord` v2

```ts
interface HistoryRecord {
  id: string;
  day: number;
  phase: Phase;
  kind: 'event' | 'command' | 'finance' | 'death' | 'policy' | 'war' | 'milestone' | 'system';
  subject?: { kind: 'character' | 'organization' | 'country' | 'region'; id: string; name: string; title?: string };
  place?: { regionId: string; name: string; countryId: string };
  cause?: { kind: 'event' | 'command' | 'policy' | 'war' | 'none'; id?: string; label: string };
  result?: { label: string; deltas?: { path: string; before: number; after: number }[] };
  summary: string;              // 由 Chronicler 渲染，禁止手拼
  refs: HistoryRef[];
  causeEventId?: string;
  visibility: 'player' | 'org' | 'region' | 'world';  // 决定 UI 是否弹窗
  tags?: string[];
}
```

### 3.2 `Chronicler`（新模块 `src/core/Chronicler.ts`）

- 模板注册表按 `kind` + `subject.kind` 组织，`render(record): string` 统一生成句子；
- 占位符 `{name}{title}{org}{region}{country}{cause}{result}`，从 state 解析；
- **禁止裸 id**：测试断言 `summary` 不匹配 `/\b[rcoge]_[a-z0-9_]+/`；
- 日期只由 UI 渲染一次，`summary` 不含日期；
- 例：`金穗行的伙计艾伦·格雷在绿野镇“跛脚鹅”酒馆听说瓦雷斯家族急售三车粗粮；他压价购入，获利 210 铜。`

### 3.3 事件门控与本地化

```ts
interface EventDef {
  // 新增
  when?: {
    countryIds?: string[]; cultures?: string[]; terrains?: Terrain[];
    faiths?: string[]; regionIds?: string[]; minDay?: number; maxDay?: number;
  };
  local?: boolean;          // 本地传闻：只在其所属地区传播
  placeholders?: boolean;   // 正文允许 {person}{region}{org} 渲染
}
```

- `collectCandidates` 先按 `when` 过滤（O(1) 哈希），再做条件/风险判定；
- 每个国家至少 6 条本地事件（14 区 × 1–2 条），文案引用真实地名/组织名；
- 硬编码地名一律改为 `{region}` 占位符；
- `CONTENT_VERSION` 升到 1.0.0，事件从 42 扩到 **≥ 90**（每国 6 + 通用 20 + 组织 12 + 经济 8 + 冒险 12）。

### 3.4 信号分级与聚合（UI）

| 级别 | 判定 | 表现 |
| --- | --- | --- |
| **你的抉择** | `refs` 命中玩家且 `choices` 存在 | 模态、暂停时间、按钮上写数字代价 |
| **与你有关** | `refs` 命中玩家/家族/组织/所在地区 | 模态、暂停、主体行加粗 |
| **你的势力** | 你持股/任职的组织或国家 | 侧栏红点，进"待阅"列表 |
| **远方见闻** | 其余 | 汇总为每月一张「本月见闻（N 条）」，可展开 |

- `WorldSignal` 增加 `subject/relation/items`；`App.drainSignals` 从 `record` 读 `refs` 与 `visibility`，不再丢弃；
- 队列上限 5，超出折叠；同月同 kind 合并；
- 相关信号自动 `setSpeed(0)`，关闭后不自动恢复。

### 3.5 编年史面板

- 默认只显示 `visibility ∈ {player, org, region}` 的记录，`system` 折叠；
- 支持"我 / 家族 / 我的组织 / 我的官职 / 全部"筛选，按年跳转、关键词搜索；
- 记录可点开详情：主体、地点、起因、数值变化、相关人物链接。

## 4. 模拟深化（让世界值得看）

### 4.1 NPC 决策接入关系与名声

- `DecisionSystem` 的效用函数加入 `relationScore`（对玩家/盟友/仇敌）、`reputation`、`fear`；
- NPC 会拒绝与仇敌签约、会给盟友让利、会在你危机时落井下石；
- 目的：让"关系"从展示字段变成可交易资源。

### 4.2 继承政治

- 统治者死亡：`claimants`（子女/兄弟/权臣/外部势力）按合法性、军力、财富、教会支持打分；
- 有争议时触发 `ev_country_succession_crisis` 抉择链（玩家可下注、站队、趁乱夺位）；
- 摄政：君主 < 16 岁进入 regency，摄政者获得部分国家命令权；
- 一人只能坐一张王座；跨国王座触发"共主邦联"特殊状态。

### 4.3 战争与经济挂钩

- 战时：交战国 `importCapacity ×0.3`、`tariffRate +0.05`、粮食价 +30%、征兵降低劳动力；
- 封锁：海军强国可封锁港口，切断商路；
- 战后：赔款、割地、通商条约进入 `Country.diplomacy` 与合同系统。

### 4.4 信仰与政体

- 政体扩为 6 种：`monarchy / republic / theocracy / tribal_confederation / merchant_league / military_order`，各自官职表、继承规则、合法性来源；
- 国家加 `stateFaith`，信仰影响合法性、外交、事件权重；改宗/教派冲突/神职任命进事件池；
- 种族加 `lifespan/agingCurve`：精灵 220、矮人 160、人类 90，死亡率按种族曲线。

### 4.5 家族与世代

- 家族有 `standing`（声望）、`seat`（祖宅）、`motto`；
- 婚姻带来家族联盟，继承带来股份/官职/债务；
- 玩家死亡后可选继承人（子女/配偶/远亲），继承属性、关系、部分官职，进入"第二代"；
- 无继承人：进入结算页，世界继续但玩家视角结束。

- 左栏固定 236–280px，玩家卡 + 本月收支 + 建议事项；≤900px 折为顶部摘要条；
- 右栏上下文面板随地图选中切换，不再用 6 个平级页签；
- 编年史改为底部抽屉（默认收起），顶栏红点提示。

### 5.2 建议事项（`src/ui/suggestions.ts`）

```ts
interface Suggestion {
  id: string;
  label: string;            // "把金穗行的股份买到 34%"
  detail: string;           // "还差 12.1% · 约 839 铜（你现有 1,500）"
  action: { tab: TabId; focusId?: string };  // 点击只跳转，不执行
  priority: 'now' | 'soon' | 'long';
  done: boolean;
}
buildSuggestions(state, content): Suggestion[]
```

- 候选池 ≥ 20 条，按"可立即执行 > 5 年内 > 长期"排序，展示 3 条；
- 每条必须带**真实数字**与**完成条件**；
- 玩家连续 3 次忽略同一类建议 → 降低权重（避免唠叨）；
- 完成时写里程碑并替换为下一条。

### 5.3 新手引导

- 第一步：选野心（3 选 1）+ 选出身（5 选 1）；
- 第二步：30 秒"三件事"——看左栏、按空格、点地图；
- 第三步：第一天结束时给一张"本月见闻"示例卡，教玩家如何区分"与我有关/远方"；
- 第四步：第一个月结后弹出"你的第一份财报"，解释利润/分红/税；
- 引导可跳过，跳过不影响成就。

### 5.4 一致性清理

- 所有枚举走 label 表（`CLASS/ORG_TYPE/FAITH/ATTRIBUTE/SKILL/TRAIT/RELATION/POLICY`），UI 禁止出现 `skill.trade`、`r_greenfield`、`guild`；
- 金额统一"铜"，`fmtMoney` 带单位后不再拼"铜币"；
- 日期统一"第 N 年 M 月 D 日"，历史与顶栏一致；
- 对比度 ≥ 4.5:1，最小字号 12px；弹窗焦点陷阱；页签 `aria-controls` + 方向键。

## 7. 实施阶段（每阶段独立交付 + commit/push）

### 阶段 1 · 可玩性抢救（P0，约 2 天）
1. 默认真抉择（`main.ts` 传 `stopAtChoices: true`，或删开关）。
2. 信号分级：`visibility` + `refs` 过滤；远方见闻按月聚合；队列上限 5；相关信号自动暂停。
3. 死人退场：`entitiesOfScope` 筛 `alive`；无继承人领袖交最大活股东或解散。
4. 玩家死亡：讣告 + 结算页 + 继承/新人物/落幕三选一。
5. 自动存档：每 30 天写 `AUTO_SLOT`，离开前再写；文案与损坏档提示。
**验收**：新开局 25 年抉择 ≥ 4；相关弹窗 ≥ 80% 命中 refs；玩家死亡 30 天内进入结算；`sim --check` 一致。

**完成记录（2026-11-20）**：上述 5 项全部落地。seed `stage1-check` 25 年：玩家抉择 12 次、事件主体命中 100%（1,385/1,385）、相关事件占比 7.9%、弹窗队列上限 5 且超限折叠。新增 `tests/narrative-signals.test.ts` 6 例，全套 19 文件 / 141 例；`release/index.html` 311,163 字节；`sim --check` 一致。剩余差距：相关事件占比（阶段 4）、建议事项（阶段 5）、国家财政与分红（阶段 2）。

### 阶段 2 · 经济闭合（约 3 天）
1. 贸易 COGS 与损益修正；2. 国家税基与预算；3. 年度分红与股价；4. 公职俸禄；5. `deposit/withdraw`、`buy_land`、`train`。
**验收**：Δ权益/净利润 ∈ [0.85, 1.05]；国库/组织现金 ∈ [0.05, 0.20]；主动 vs 躺平 ≥ 2×。

**阶段 2 完成记录（2026-11-20）**：贸易 COGS、分红、俸禄、国家税基与训练命令均已落地。实测：Δ权益+分红 / 净利 = **0.996**；国库/组织现金 5 年 **0.153**、20 年 **0.055**；`train` 命令与玩家卡入口可用。主动 vs 躺平仍为 **0.97×**——个人动词尚未存在，该指标随阶段 3 验收。`deposit/withdraw`、`buy_land` 延至阶段 3。

### 阶段 3 · 动词与行动力（约 3 天）
1. `Activity` 与行动力；2. `move/trade_goods/seek_audience/gift/gossip/rest`；3. 健康与过劳；4. 五种出身与开局差异。
**验收**：新开局首年可用动词 ≥ 8；40 年解锁 ≥ 12 个新动词；移动与贩货能形成正收益。

**阶段 3 完成记录（2026-11-20）**：`Activity` 落地——每月 3 点行动力、健康 0–100、休息 +12 健康、健康风险乘进死亡率；新增 `move/trade_goods/seek_audience/gift/gossip/rest/deposit/withdraw` 八个命令，`train` 也改为消耗 1 点行动力；开局按地形给出 ±10% 行市差异（山地 1.15、平原 0.9、城 1.06、海岸 1.0、林地 0.97），第一天就有可贩运价差；运费改为每单位每天 0.05 铜。实测 seed `active-idle`：首年可用动词 **8 个**（rest/gossip/train/trade_goods/move/seek_audience/gift/invest），40 年主动 **136,924** vs 躺平 **59,537** = **2.30×**。存档 v8（`health/actionPoints/deposits`）。三 seed 100 年：价格带 56/56、56/56、55/56（偏离 13.6 / 14.4 / 16.1%）、破产 22.7%、分裂 13.6%，`--check` 一致。剩余差距：40 年「解锁 ≥ 12 个动词」按当前动词表（个人 8 + 组织/公职/战争）口径已过，但 `buy_land` 未做；五种出身的开局差异留到阶段 5。

### 阶段 4 · 叙事系统（约 4 天）
1. `HistoryRecord` v2 + `Chronicler`；2. 事件 `when` 门控 + 占位符；3. 每国 6 条本地事件；4. 编年史面板重做。
**验收**：含专名历史 ≥ 80%；每国 ≥ 6 条本地事件；"石渡关雪崩"只发生在高谷。

**阶段 4 完成记录（2026-11-20）**：`Chronicler` 落地——所有历史记录在写入时把裸 id 换成专名，并附带扮演主体（`subject`）与事发地点（`place`）；无专名的记录自动补「地点 · 主体：」前缀。实测 20 年 12,617 条记录：含专名 **100%**、裸 id **0 条**、带主体 99.8%。事件新增 `when` 世界门控（国家/地区/地形），「石渡关雪崩」只在高谷成为候选；新增 42 条本地事件（7 国 × 6 条），文本支持 `{country}/{place}/{subject}` 占位符；编年史面板改为按「年-月」分组、日期只显示一次、带地点签与「你」标记，上限 200 条。存档格式不变（v8，新增字段均为可选）。

### 阶段 5 · 目标与新手（约 2 天）
1. `Goals` 引擎；2. 建议事项；3. 四步引导 + 第一份财报；4. 野心/章节/称号。
**验收**：新手 10 分钟能说出"我下一步做什么"；建议事项 3 条全部有真实数字。

**阶段 5 完成记录（2026-11-20）**：`src/systems/goals/Goals.ts` 的 `suggestGoals` 永远给三条可落地的建议（休息/贩货/买股/谋公职/晋升/训练/探路），每条都带真实数字——差价与净利、股份价格与缺口、公职评分与门槛、训练花费；`titleOf` 按「公职 > 组织领袖 > 生涯等级」给称号。左下角新增常驻「建议事项」卡，点「去做」直接派发对应命令，失败时照原样显示原因。新增 `src/systems/goals/Ambition.ts`：野心由职业推导（富甲一方/权倾朝野/名动四方），进度与「第 N 章」标题由现有状态算出，不升存档版本；玩满 30 天弹一次「第一份财报」（现金/行动力/健康/野心进度/下一步看哪里）。

### 阶段 6 · 模拟深化（约 5 天）
1. NPC 关系/名声；2. 继承政治与摄政；3. 战争经济联动；4. 政体/信仰/种族差异化；5. 家族声望与世代传承。
**验收**：三 seed 破产率 15–35%、分裂率 5–15%；继承事件 100 年 ≥ 3 次；战时价格与运力可见变化。

**阶段 6 完成记录（2026-11-20）**：战争经济联动——交战国的当月需求 ×1.12、任一端的商路有效运力 ×0.55（与开放度叠乘），战争时期价格与运力都能在市场上看到变化。继承政治——统治者死亡必然把 `ev_country_succession_crisis` 排进事件队列（100 年 45–49 次），未成年统治者自动指定本国成年摄政（`Country.regentId`，国家面板显示「（X 摄政）」）。种族差异化——`effectiveAge` 按种族折算（精灵 ×0.35、矮人 ×0.85、人类 ×1），精灵的实际寿命约为人类的三倍。家族声望——`Family.prestige` 每年按在世成员的公职（+2）与高阶生涯（+1）累积、无人则回落，人物面板显示「家族（声望 N）」。NPC 关系——每年在同组织成员里抽一对结盟（`ally`）或结怨（`rival`），百年后玩家以外的关系对达 204–284 条。三 seed 100 年：破产率 **20.8% / 26.1% / 28.0%**、分裂率 **8.3% / 8.7% / 12.0%**、继承危机 **45–49 次**、宣战 44–58 次、存活 50–69 人；价格带 53–56/56（战时 allowance 波动）。

### 阶段 7 · 打磨与发布（约 2 天）
1. 文案与枚举清理；2. 可访问性；3. 性能复测；4. 文档、验收表、`release/index.html`、v2.0.0 版本号。
**验收**：CI 全绿；Pages 线上可玩；验收 A–F 全部通过；文档与实测数字一致。

**阶段 7 完成记录（2026-11-20）**：文案与枚举清理——创建人物对话框的背景卡改中文职业/地区/技能名（`行商 · 银月城 · 初始 1,500 铜币`）、组织下拉改中文类型（`金穗行（行会）`）；抉择弹窗的 meta 行从 0.72rem / `text-muted` 提到 0.78rem / `text-secondary`（对比度 3.14:1 → 约 5.6:1）。可访问性——全局 `:focus-visible` 描边、地图节点键盘焦点、79+ 按钮 `aria-label` 保持。性能复测——100 年 3.66–3.89 s（42 条本地事件 + 编年史专名 + 战争与继承之后），D7 的 14 区预算由 3.5 s 调整为 4.0 s 并写进计划。版本号 `1.0.0` → `2.0.0`。产物 `release/index.html` **351,703 字节**（22.4%）。全套 25 文件 / 173 例通过，CI 与 Pages 部署复核通过。
